# Security

Report a vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/geovicco-dev/bhoonidhi-stac/security/advisories/new),
not in a public issue. Include the steps to reproduce it and what an attacker
could do with it. You will get a reply within a week.

The catalogue at https://bhoonidhi-stac.ecotrakr.in is read-only: it has no
user accounts, stores no Bhoonidhi credentials, and serves metadata only.
